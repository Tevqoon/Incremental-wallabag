Import from a URL

One Substack post, fetched directly rather than through wallabag's own extraction — which routinely drops structure, headings most visibly. Creates the entry in wallabag if it does not exist there yet, or replaces its content in place if what is there is not the full article, re-anchoring any highlights already made on it either way.

Check for new articles

Re-walks the whole archive of the publication configured in ingest.substack and reconciles anything new — or anything still showing as a paywall preview — into wallabag, the same as increader import-substack run by hand. Already-fetched posts are served from cache, so this is quick after the first run, but it still pages through the archive listing itself every time, which can take a few minutes on a large publication — the page will sit on this request until it finishes.
